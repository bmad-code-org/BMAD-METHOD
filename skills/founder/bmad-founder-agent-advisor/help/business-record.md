# The business record

Nadia (`bmad-founder-agent-advisor`) keeps what she learns in a business record folder in the project, chosen when Founder is set up (default `company/`; in a vault, the folder its AGENTS.md names for the business). Its `README.md` gives the layout. Every document she coaches quotes it, so the figures match everywhere.

- Documents are written to the output folder like any `bmad-facilitate` document; the record points at the current one for each ask.
- It holds fundraising and personal detail; whether it goes in version control is the team's call.
