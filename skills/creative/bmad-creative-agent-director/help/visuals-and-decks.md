# Visuals, presentations, and rehearsal

All guided through Clio (`bmad-creative-agent-director`).

Finished work comes as a rich, self-contained visual page by default (SVG diagrams, infographics, callouts, interaction, generated images when the host has an image tool), with the markdown kept as the record. Work presented as the creator or their organization follows the project's brand or design system, set as the `design_system` setup answer; fiction and invented worlds take their own look. To prefer markdown, tables, or Mermaid, change Clio's `view`, `visuals`, or `style` with `bmad-customize`.

- Narrative or visual slide deck where a presenter speaks -> `presentation` in `bmad-facilitate`, rendering a self-contained HTML deck with keyboard navigation, speaker notes (`N`), one-slide-per-page print view, and visual treatments tailored to each slide instead of bullet cards. (Send startup investor decks with traction, market sizing, and a funding ask to Nadia in `founder`.)
- Keynote, conference talk, podcast, or spoken script -> `talk-script` (or `BRAINDUMP` followed by `WEAVE`), producing a teleprompter and beat timeline view.
- Prioritize cuts and visual upgrades on slides, outlines, or diagrams -> `CRITIQUE` applies the 3-second test, traces the eye path, bans static text-only cards, and lists exact replacements.
- Build a visual metaphor, staged diagram, stat treatment, timeline, comparison, SVG, Mermaid chart, interactive HTML figure, or editable `.excalidraw` file -> `VISUAL` escalates content into visuals rather than prose paragraphs.
- Practice delivery aloud -> `REHEARSE` checks spoken cadence, measured WPM runtime, 60-to-90-second pattern resets, and open loops, then roleplays skeptical audience Q&A.
- Route software application UX and screen design (`DESIGN.md`, `EXPERIENCE.md`) to Sally (`bmad-agent-ux-designer`).
