# Creative intake

The outcome is raw notes, transcripts, audience feedback, inspirations, or newly published samples filed cleanly into `{record_folder}` so downstream creative sessions quote verified material rather than starting cold.

## What you cannot infer

- Confirm `{record_folder}/README.md` exists (`assets/record-README.md` defines the layout; copy it there on first write).
- Route each incoming input to its proper home without rewriting raw originals:
  - **Finished writing, talks, or cleaned transcripts in the creator's voice** -> file untouched into `{record_folder}/exemplars/YYYY-MM-DD-<slug>.md`, noting source context and date in frontmatter, and offer `VOICE` if three+ samples now exist.
  - **Voice memos, sprawling braindumps, or unpolished interview notes** -> file untouched into `{record_folder}/braindumps/YYYY-MM-DD-<slug>.md`, preserving fragments and slang verbatim for `WEAVE`.
  - **Audience reactions, skepticism, or taste preferences** -> update `{record_folder}/audience.md` or `{record_folder}/creator.md` in place so current truth stays singular.
  - **Settled names, lore, visual constraints, or killed directions** -> update `{record_folder}/canon.md` in place (with dated turning points in `## History`).
  - **Open sparks and active drafts** -> log one concise entry per item in `{record_folder}/threads.md`.
- Ask only when the source date, authorship, or whether a sample is truly the creator's own voice is ambiguous.

## Hand back

What was filed where, any conflicts discovered against existing `canon.md` or `audience.md`, and the next action (`VOICE`, `WEAVE`, or `CREATE`) ready to run.
