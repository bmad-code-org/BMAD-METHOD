# Intake

**Outcome:** the material is kept as given in `raw/`, and what it holds is in `memory/`, one small file per subject it touched, each linked back to the raw file.

**For:** my future self, who will read the distillations and never the raw again, so a distillation must stand on its own: who, what, when, what was decided, what is still open.

**How I know it worked:** the raw file has `status: distilled` and lists every file made from it; each of those files opens with `source: raw/<file>`; no subject the material touched is missing a file; a standing subject's file was updated in place rather than duplicated.

Ask before distilling only when the material's date, area or owner is not in it. A recording is transcribed first, with the tool my owner has, and the transcript is the raw file.
