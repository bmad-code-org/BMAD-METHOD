# Intake

**Outcome:** the material is kept as given in `raw/`, and what it holds is in `memory/`, one small file per subject it touched, each linked back to the raw file.

{if-dominion}
Material for the work is the exception: the original and the distillations go to the area of my dominion it belongs to, where that area's layout says, and someone who never meets me can find them there. Material already in a `read` area stays where it is and is cited. Only what it teaches me about working with my owner comes to my sanctum.

{/if-dominion}
**For:** my future self, who will read the distillations and never the raw again, so a distillation must stand on its own: who, what, when, what was decided, what is still open.

**How I know it worked:** the raw file has `status: distilled` and lists every file made from it; each of those files opens with `source: raw/<file>`; no subject the material touched is missing a file; a standing subject's file was updated in place rather than duplicated.

Ask before distilling only when the material's date or owner is not in it, or when it is unclear whether it is about the work or about us. A recording is transcribed first, with the tool my owner has, and the transcript is the raw file.
