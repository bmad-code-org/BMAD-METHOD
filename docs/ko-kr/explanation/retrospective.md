에픽이 끝나면 `bmad-retrospective`를 실행하세요. 이 스킬은 에픽이 실제로 만든 사양, 전체 diff, 스토리별 커밋, 스프린트 상태를 읽습니다. 사람이 작업 과정을 어떻게 기억하는지에 기대지 않고 이 증거로 검토합니다. 결과는 서면 검토, 담당자가 정해진 실행 항목, 에픽이 기준을 충족했는지에 관한 판정입니다.

## 수행하는 작업

에픽은 각각 따로 구현하고 검토한 여러 스토리가 쌓여 완성됩니다. 회고는 이를 한꺼번에 살펴보고 개별 스토리만으로는 알 수 없던 내용을 찾아냅니다.

- **누적 결함** — 조금씩 어긋난 아키텍처, 두 번 작성된 도우미, 여러 차례 몇백 줄씩 늘어나 결국 과도하게 커진 클래스
- **diff 범위 검토** — 에픽의 diff를 `bmad-review`에 전달해 코드 관점별로 검토하며, 개별 세션에서 양쪽을 함께 보지 못한 스토리 간 경계를 중점적으로 살펴봄
- **사양 대조** — 구현된 코드가 에픽과 PRD에서 설명한 내용과 달라진 부분
- **인수 판정** — 에픽 자체의 인수 조건에 따른 결과 평가

모든 발견 사항에는 파일, 줄, 커밋, 로그 같은 출처 참조가 붙습니다. 근거를 가리킬 수 없는 주장은 보고서에 포함하지 않습니다.

## 에픽이 끝난 뒤 실행하는 이유

각 스토리는 서로 분리된 상태에서 자체 검토를 통과했습니다. 이 단계까지 남은 버그는 분리된 검토가 감추는 문제입니다. 아홉 번의 세션이 같은 파일에 조금씩 코드를 추가하면 개별 세션에서는 여러 작업이 합쳐져 커진 클래스를 전체적으로 보지 못합니다. 에픽 전체가 처음 세운 목표를 달성했는지 판단한 세션도 없습니다. 회고는 이 전체 관점의 빈틈을 메웁니다. diff가 아직 최신이고 세션 로그가 지워지기 전인 에픽 종료 시점이 가장 적절합니다.

:::note[증거를 읽을 뿐, 만들어 내지 않습니다]
회고는 diff, 커밋, 사양에 실제로 드러난 내용을 보고합니다. 코드로 뒷받침할 수 없는 근본 원인이나 패턴을 지어내지 않습니다.
:::

## 얻게 되는 결과

두 가지 산출물과 한 가지 결정을 받습니다.

- **회고 문서** — 구현 산출물에 저장하며 증거 목록, 출처와 함께 묶은 발견 사항, 판정, 실행 항목을 담습니다.
- **업데이트된 스프린트 상태** — 에픽의 회고를 완료 상태로 표시합니다. 각 실행 항목에는 안정적인 ID와 해당 발견 사항으로 돌아가는 링크를 붙입니다.
- **판정** — `accepted`, `accepted-with-open-items`, `rejected` 중 하나입니다. 다음 에픽을 시작할지, 멈추고 먼저 수정할지 알려줍니다. 해당 에픽에 끝나지 않은 스토리가 있으면 자동 판정은 **rejected**입니다. 대화형 실행에서는 사람이 이를 재정의할 수 있습니다.

## 결과 활용하기

스킬은 제안만 합니다. 무엇을 실행할지는 사용자가 결정합니다. 코드나 사양을 자동으로 수정하지 않습니다.

- **실행 항목**은 즉시 수정할 작업이나 새 스토리로 일반 개발 루프에 들어갑니다. 회고는 항목을 작성하지만 실행하지 않습니다.
- **사양 대조 결과**에는 증거가 함께 제공됩니다. 프로젝트 계약에 직접 반영할 수 있습니다. 해석이 불확실한 내용은 사양에 자동으로 기록하지 않습니다.
- **판정**은 게이트 역할을 합니다. `rejected` 또는 `accepted-with-open-items` 판정은 다음 계획 단계로 넘겨야 할 내용을 알려줍니다.

실패한 에픽을 조용히 승인된 상태로 닫는 일은 없습니다. 인수 조건을 충족하지 못했거나 에픽의 스토리가 하나라도 끝나지 않았는데 판정을 재정의한 사람도 없다면, 승인되지 않은 상태로 종료합니다.

## 실행하기

"회고를 실행해 줘" 또는 "에픽 3을 회고해 줘"라고 입력하세요. 스프린트 상태에서 완료된 에픽을 찾거나 사용자가 지정한 에픽을 사용합니다. 기본적으로 보고서와 판정을 작성한 뒤 멈춥니다.

| 원하는 작업 | 실행 방법 |
| --- | --- |
| 표준 검토 | "회고를 실행해 줘" |
| 특정 에픽 검토 | "에픽 3을 회고해 줘" |
| 팀 토론 | "팀과 함께 논의해 줘"라고 요청합니다. 실제 발견 사항을 두고 [party mode](./party-mode.md)를 진행합니다. 기본값은 꺼짐입니다. |
| 자동화를 위한 무인 실행 | `-H <epic>` — 증거만으로 판정하는 헤드리스 모드 |
