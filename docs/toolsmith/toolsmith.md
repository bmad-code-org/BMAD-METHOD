Toolsmith is the module for authoring BMad content. Its agent, Smithy (`bmad-toolsmith`), builds a skill of any shape through the approach that fits, packages it as a module, and knows the skills around it. `bmad-eval` measures whether a skill works. Toolsmith installs from the BMAD-METHOD repository and is not part of a default method install.

This section is being written alongside the agent. Each page below is reserved for one part of it.
