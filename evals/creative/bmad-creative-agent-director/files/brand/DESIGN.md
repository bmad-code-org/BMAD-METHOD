# Lantern Library Co-op — Design System

A member-owned lending library. The brand is warm, civic, and plain-spoken.

## Color

| Token | Value | Use |
|---|---|---|
| `ink` | `#1F4E5F` | Headlines, primary text on light |
| `lamp` | `#E8A33D` | One accent per screen: the number or call to action |
| `paper` | `#FBF7EF` | Backgrounds |
| `shelf` | `#8C6A4F` | Rules, borders, secondary marks |

No gradients. One accent per view.

## Type

- Display: Fraunces, falling back to Georgia, serif.
- Body: Source Sans 3, falling back to system-ui, sans-serif.

## Marks

The lantern mark is a simple outlined lantern with a single amber flame. It sits top left, never larger than 48px tall.
