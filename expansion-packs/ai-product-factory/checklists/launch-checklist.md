# Launch Checklist — AI Product Factory

Complete before declaring a product "launched".

## Founder Layer
- [ ] Idea validated (GO or CONDITIONAL GO)
- [ ] Market research complete
- [ ] Competitive analysis done
- [ ] Personas defined
- [ ] Lean Canvas finalized
- [ ] Pricing strategy set

## Product Layer
- [ ] PRD finalized (status: final)
- [ ] MVP features prioritized
- [ ] Roadmap created
- [ ] Epics and stories written
- [ ] Acceptance criteria defined

## UX & Design
- [ ] User flows mapped
- [ ] Wireframes complete
- [ ] Navigation architecture defined
- [ ] Accessibility audit passed
- [ ] Brand guidelines set
- [ ] Design system documented

## Engineering
- [ ] Tech stack selected
- [ ] Architecture documented
- [ ] MVP implemented
- [ ] Tests passing (>80% critical paths)
- [ ] Security audit passed
- [ ] Code review complete

## Deployment
- [ ] CI/CD pipeline configured
- [ ] Staging environment verified
- [ ] Production deployed
- [ ] App store submitted (if mobile)
- [ ] Domain configured (if web)
- [ ] SSL/HTTPS active
- [ ] Monitoring and alerts set up

## Marketing
- [ ] Landing page live
- [ ] SEO optimized
- [ ] Privacy Policy published
- [ ] Terms of Service published
- [ ] FAQ published
- [ ] Social launch content ready
- [ ] Product Hunt listing prepared
- [ ] Email sequences configured

## Analytics
- [ ] Analytics provider integrated
- [ ] Key events tracked
- [ ] Conversion funnel defined
- [ ] Dashboard accessible

## Post-Launch
- [ ] First growth experiment designed
- [ ] Feedback collection mechanism active
- [ ] Iteration backlog prioritized
