# UX Checklist — AI Product Factory

Verify before handing off from UX to Design/Engineering.

## User Flows
- [ ] Onboarding flow defined
- [ ] Core value loop mapped
- [ ] Error states documented
- [ ] Empty states designed
- [ ] Loading states specified
- [ ] Settings/account flow mapped
- [ ] Paywall flow (if applicable)

## Navigation
- [ ] Primary navigation pattern selected
- [ ] Information architecture defined
- [ ] Deep linking map created
- [ ] Back navigation behavior specified

## Wireframes
- [ ] All MVP screens wireframed
- [ ] Content hierarchy clear
- [ ] Interaction notes included
- [ ] Responsive breakpoints noted

## Accessibility
- [ ] Color contrast meets WCAG AA
- [ ] Touch targets ≥ 44x44pt
- [ ] Screen reader flow verified
- [ ] Keyboard navigation (web)
- [ ] Focus indicators defined

## Platform Compliance
- [ ] Apple HIG (iOS)
- [ ] Material Design (Android)
- [ ] Platform-specific patterns applied
