# Landing Experiment Kit

Use this kit when an experiment needs a landing page rather than a full product.

1. Run `bmad-apf-validate-opportunity`.
2. Run `bmad-apf-design-experiment` with a conversion signal and stop rule.
3. Use `bmad-apf-execute` only for the minimal page, analytics, and legal capability required.
4. Run `bmad-apf-learn-and-iterate` from observed results.
