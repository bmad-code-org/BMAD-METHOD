# Mobile Product Kit

Use this kit for a mobile prototype, MVP, or production release.

1. Select a lifecycle track with `bmad-apf-launch-product`.
2. Delegate product and UX planning to BMAD through `bmad-apf-plan-product`.
3. Select the mobile adapter only in `bmad-apf-plan-delivery`.
4. Build reversible slices and select store release gates only when releasing.
