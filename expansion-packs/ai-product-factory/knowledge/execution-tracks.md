# APF Execution Tracks

Use this reference only when `bmad-apf-launch-product` is selecting or changing a lifecycle route.

- **Experiment:** demand evidence before product construction.
- **Prototype:** UX or technical feasibility before a delivery commitment.
- **MVP:** one complete value loop; no automatic production hardening.
- **Production:** reliability, security, observability, operations, rollback, and compliance as applicable.
- **Brownfield:** current-project contract first; avoid repeating founder discovery.

Changing tracks requires a new gate decision and may change the selected verification level.
